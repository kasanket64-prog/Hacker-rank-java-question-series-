# HackerRank Java Practice

An introductory Java practice repository for learning program structure and basic standard output.

## Available exercise

[`Q1.java`](Q1.java) prints `Hello, World.` and `Hello, Java.`.

Compile and run with a Java Development Kit:

```bash
javac Q1.java
java Q1
```

**Submission note:** Some HackerRank tasks require the public class `Solution`. This local example uses `Q1`, so follow the exact requirements of each challenge before submission.
